Browse plugins made by the community from the UnderScript menu, and install them from there.

The list is sorted by name, with each plugin's author under its name, and has a search bar that looks through names and authors. Buttons next to it hide the plugins you don't want to see, based on their status.

For each plugin it shows the version you have, the latest version, and when that latest version was last updated. The date is looked up once a day, and it is only shown while it belongs to the latest version, so a brand new version has no date until the next lookup.

Plugins add new features to UnderScript. Want to make your own? The [Plugin Generator]({{ site.baseurl }}{% link generator.html %}) gives you a plugin to start from without writing any code, and the [Plugin API]({{ site.baseurl }}{% link _api/index.md %}) lists everything a plugin can do.
