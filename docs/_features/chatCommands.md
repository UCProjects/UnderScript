### /spectate [text]
Sends `You vs Opponent: link [text]`. Text is optional

### /gg
Sends `good game @o`

### /scroll
Scrolls the chat window to the bottom

The suggestion list shows which script each command comes from. If two scripts have the same command, the suggestion completes to `/owner:command`, with the owner's name and dashes instead of spaces, so you can pick the one you want. Typing that form yourself works too. Typing the start of a script's name, such as `/under`, lists that script's commands as well, after the commands whose own names match.

Scripts can add their own commands too, and the suggestions show which script each one comes from.
